1. ISSUE SUMMARY
-------------------------------------------------------------------------------
Navigating to `https://university-event-management-web-phi.vercel.app/admin/login`
returns a Next.js 404 "Page Not Found" page.

-------------------------------------------------------------------------------
2. ROOT CAUSE DIAGNOSIS
-------------------------------------------------------------------------------
The route `/admin/login` returns 404 because NO page route file exists under
`apps/web/src/app/admin/login/page.tsx` or `apps/web/src/app/admin/page.tsx`.

Under Next.js App Router, routes map directly to filesystem directory structures:
- `apps/web/src/app/page.tsx` -> `/`
- `apps/web/src/app/events/page.tsx` -> `/events`
- `apps/web/src/app/events/[id]/page.tsx` -> `/events/[id]`
- `apps/web/src/app/events/[id]/display/page.tsx` -> `/events/[id]/display`
- `apps/web/src/app/attendance/session/[token]/page.tsx` -> `/attendance/session/[token]`
- `apps/web/src/app/admin/events/[id]/attendance/page.tsx` -> `/admin/events/[id]/attendance`

Because there is no folder/file at `apps/web/src/app/admin/login/page.tsx`, Next.js
naturally responds with a standard 404 error page.

-------------------------------------------------------------------------------
3. EXISTING ADMIN AUTHENTICATION ARCHITECTURE
-------------------------------------------------------------------------------
In the existing codebase, admin authentication was designed as an INLINE MODAL
FLOW rather than a standalone `/admin/login` page:

1. Target Route:
   Administrators manage attendance per event via:
   `apps/web/src/app/admin/events/[id]/attendance/page.tsx`
   URL: `/admin/events/[id]/attendance`

2. Inline Auth Check:
   When the Admin Attendance page loads, `useEffect` checks local storage:
   `const token = localStorage.getItem('admin_access_token');`
   - If a valid token exists, it calls GET `/api/attendance/event/:id` with the
     `Authorization: Bearer <token>` header.
   - If token is missing, expired, or rejected (401/403), state `showAuthModal`
     is set to `true`.

3. Inline Auth Modal:
   An overlay modal renders directly inside the page asking for Admin Credentials
   (Username & Password).

4. API Interaction:
   - Form submits to `POST /api/auth/admin/login` with body `{ username, password }`.
   - On success (200 OK), receives `{ accessToken, user }`.
   - Saves token: `localStorage.setItem('admin_access_token', res.accessToken)`.
   - Hides modal and fetches admin event attendance records.

5. Navigation UI:
   - Navbar (`apps/web/src/app/components/Navbar.tsx`): Has no dedicated `/admin/login` link.
   - Event Detail (`apps/web/src/app/events/[id]/page.tsx`): Contains an "Admin Console"
     action button pointing directly to `/admin/events/${id}/attendance`.
