14. MANUAL CONFIGURATION REQUIRED
---------------------------------
1. Create hosting project on Vercel / Railway / Render / AWS.
2. Provision managed PostgreSQL database and set `DATABASE_URL`.
3. Provision S3-compatible cloud storage bucket and set `S3_BUCKET`, `S3_REGION`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`.
4. Configure production environment variables (`JWT_SECRET`, `FRONTEND_URL`, `NEXT_PUBLIC_API_URL`, `ADMIN_INIT_USERNAME`, `ADMIN_INIT_PASSWORD`).
5. In LINE Developers Console, set Webhook URL to `https://<backend-domain>/api/line/webhook` and enable Webhook.
6. In LINE Developers Console, configure LIFF Endpoint URL to `https://<frontend-domain>/attendance/session/` and set `NEXT_PUBLIC_LIFF_ID`.
