1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 11 establishes a production-grade foundation for LINE Official Account (OA),
LIFF (LINE Front-end Framework), and push notifications integration into the
University Event Management System.

Key Achievements:
- Real LINE OAuth2 Token Verification: Implemented backend verification via official
  LINE OAuth2 endpoint (`https://api.line.me/oauth2/v2.1/verify`). Client claims are
  never blindly trusted.
- HMAC-SHA256 Webhook Verification: Implemented strict signature verification for
  `POST /api/line/webhook` using `LINE_CHANNEL_SECRET`.
- Production Push Messaging with Idempotency: `LineMessagingService` includes
  duplicate notification prevention using in-memory idempotency tracking during
  projector polling.
- Clean LIFF Frontend SDK Integration: Created `@line/liff` wrapper with graceful
  fallback to browser development switcher when LIFF SDK is unconfigured or running locally.
- Student Account Linking Lifecycle: Implemented secure mapping between verified
  LINE User IDs (`lineUserId`) and academic Student records (`studentId`).


2. ARCHITECTURE & IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------
A. Backend (NestJS API `apps/api/src/line`):
   - `LineService`:
     * `verifyIdToken(idToken)`: POSTs to LINE OAuth2 API with `client_id` & `id_token`.
     * `authenticateOrCheckStatus(idToken)`: Checks `Student` record by `lineUserId`. Issues JWT session token if linked.
     * `linkStudentAccount(idToken, studentId)`: Validates ID token and links `lineUserId`, `lineDisplayName`, `linePictureUrl`.
   - `LineMessagingService`:
     * `sendPushMessage(lineUserId, messages, idempotencyKey)`: Sends push notifications via LINE Messaging API (`https://api.line.me/v2/bot/message/push`).
     * `notifyEventCreated(event)`: Broadcasts new event announcements.
     * `notifyCheckInOpened(event, token)`: Pushes check-in session opening notification with direct attendance link.
     * `notifyCheckOutOpened(event, token)`: Pushes check-out session opening notification.
   - `LineController`:
     * `POST /api/line/verify-token`: Verifies LIFF ID token.
     * `POST /api/line/link-student`: Links LINE account to student profile.
     * `POST /api/line/webhook`: Receives LINE webhook events and validates HMAC-SHA256 signature.

B. Frontend (Next.js `apps/web`):
   - `apps/web/src/lib/liff.ts`: Lazy-initializes LIFF SDK via `@line/liff`.
   - `apps/web/src/lib/attendance-api.ts`: Exports `verifyLineToken` and `linkStudentAccount`.
   - `StudentAttendanceForm.tsx`: Renders LINE status badge and "Link LINE Account" button when unlinked.

4. STEP-BY-STEP MANUAL SETUP GUIDE: LINE DEVELOPERS CONSOLE
--------------------------------------------------------------------------------
To connect this codebase to a live LINE Official Account and LIFF app:

STEP 1: Create LINE Provider & Messaging API Channel
1. Go to LINE Developers Console: https://developers.line.me/
2. Sign in with your LINE account.
3. Click "Create a new provider" (e.g., "University Event System").
4. Under the Provider, click "Create a Messaging API channel".
5. Fill in Channel Name, Description, Category, and Email.
6. Once created, open the "Basic settings" tab:
   - Copy "Channel ID" -> set as `LINE_CHANNEL_ID` in `.env`
   - Copy "Channel secret" -> set as `LINE_CHANNEL_SECRET` in `.env`
7. Open the "Messaging API" tab:
   - Scroll down to "Channel access token (long-lived)" and click "Issue".
   - Copy the token -> set as `LINE_CHANNEL_ACCESS_TOKEN` in `.env`
   - Under "Webhook settings", enter your public HTTPS URL (e.g. via ngrok or production domain):
     `https://your-domain.com/api/line/webhook`
   - Enable "Use webhook".

STEP 2: Create LIFF Application (LINE Front-end Framework)
1. In LINE Developers Console under your Provider, click "Create a new channel".
2. Select "LINE Login".
3. Fill in Channel Name and Description.
4. Go to the "LIFF" tab and click "Add".
5. Configure LIFF App:
   - LIFF app name: "University Event Attendance"
   - Size: Full
   - Endpoint URL: `https://your-domain.com/attendance/session/` (or your frontend deployment URL)
   - Scope: `profile`, `openid`
   - Bot prompt: Aggressive or Normal
6. Click "Add".
7. Copy the generated "LIFF ID" (e.g., `1234567890-AbCdEfGh`) -> set as `NEXT_PUBLIC_LIFF_ID` in `.env`.

STEP 3: Environment Configuration (`.env`)
Ensure your root `.env` contains:
```
LINE_CHANNEL_ID=your_messaging_channel_id
LINE_CHANNEL_SECRET=your_messaging_channel_secret
LINE_CHANNEL_ACCESS_TOKEN=your_channel_access_token
NEXT_PUBLIC_LIFF_ID=your_liff_app_id
```

Restart your NestJS API and Next.js Web server to apply the updated environment.
