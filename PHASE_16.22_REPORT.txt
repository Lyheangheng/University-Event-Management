6. FINAL QR VERIFICATION
------------------------------------------------------------------------------
- Persistent Dual-QR Architecture:
  - CHECK_IN QR: Static persistent token stored in `attendance_sessions`. Same URL returned across repeated retrievals.
  - CHECK_OUT QR: Static persistent token stored in `attendance_sessions`. Same URL returned across repeated retrievals.
  - CHECK_IN token != CHECK_OUT token.
- LIFF URL Format: `https://liff.line.me/2011689671-SKaMIQlb?token={SESSION_TOKEN}`
- Time Window Bounds:
  - CHECK_IN: `event.startTime` -> `event.startTime + 30 minutes`
  - CHECK_OUT: `event.endTime - 30 minutes` -> `event.endTime + 30 minutes`
  - Server clock is the sole authority; client clock/countdown cannot override backend bounds.
