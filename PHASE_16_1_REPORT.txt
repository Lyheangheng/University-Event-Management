4. EXACT PRODUCTION MIGRATION COMMAND
--------------------------------------
To safely apply the existing migrations to the production Supabase database without resetting or modifying existing data, run:

  npx prisma migrate deploy

Usage options:

Option A — From local terminal targeting production Supabase:
  DATABASE_URL="<your-production-supabase-connection-string>" npx prisma migrate deploy

Option B — Configured in Render Build Command:
  npx prisma migrate deploy && npm run build

5. REQUIRED MANUAL CONFIGURATION
--------------------------------
- Ensure the production Supabase `DATABASE_URL` is set in the environment before running `npx prisma migrate deploy`.
- Optional: If initial production admin bootstrapping is desired after migration deployment, run `npx prisma db seed` with production `ADMIN_INIT_USERNAME` and `ADMIN_INIT_PASSWORD` environment variables set.
