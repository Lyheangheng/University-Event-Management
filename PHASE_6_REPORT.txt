7. Event State Machine:
   - BEFORE_EVENT: Current time < startTime
     Display: "EVENT STARTING SOON", countdown to event start time.
   - CHECK_IN_WINDOW: Current time >= startTime AND Current time < startTime + 10 minutes
     Display: "CHECK-IN OPEN", countdown of remaining check-in time, QrPlaceholder.
   - BETWEEN_CHECK_IN_AND_CHECKOUT: Current time >= startTime + 10m AND Current time < endTime - 15m
     Display: "CHECK-IN CLOSED", "Please wait for check-out", countdown to checkout window.
   - CHECK_OUT_WINDOW: Current time >= endTime - 15m AND Current time < endTime
     Display: "CHECK-OUT OPEN", countdown of remaining check-out time, QrPlaceholder.
   - ENDED: Current time >= endTime
     Display: "EVENT ENDED", event end time.

8. Countdown Implementation:
   - Implemented 1-second setInterval ticker in client component.
   - Pure state calculator (getEventDisplayState, getCountdownTarget, formatCountdownMs).
   - Dynamically calculates remaining HH : MM : SS digits without displaying negative values.
   - Cleans up timer interval on component unmount.

9. Time Handling Approach:
   - Combines backend ISO 8601 timestamps (startTime, endTime) into JavaScript Date objects.
   - Performs comparisons against live local browser time.

10. UI Implementation:

    - Large digital typography readable from a distance on classroom projectors.

11. QR Placeholder Implementation:
