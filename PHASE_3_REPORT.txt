5. Admin Authentication Implementation:
   - Endpoint: POST /api/auth/admin/login
   - Body validation via AdminLoginDto (username, password).
   - Looks up Admin by username in PostgreSQL database.
   - Compares password against stored passwordHash using bcrypt.compare().
   - Generates signed JWT upon success and returns accessToken and admin profile
     (id, username, name). Excludes passwordHash.
   - Generic 401 Unauthorized returned on invalid credentials.

6. JWT Configuration:
   - Integrated with ConfigService via JWT_SECRET and JWT_EXPIRES_IN environment variables.
   - Added safe template placeholders to .env.example and development values to .env.
   - JWT Payload structure: { sub: admin.id, username: admin.username, role: 'ADMIN' }.

7. Password Hashing Implementation:
   - Utilizes bcryptjs with 10 salt rounds.
   - Passwords and hashes are never logged or returned in API responses.
