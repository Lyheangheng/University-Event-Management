1. OVERVIEW & DESIGN PHILOSOPHY
-------------------------------------------------------------------------------
Phase 17.1 systematically replaced all AI SaaS-style visual elements (purple/blue
gradients, neon glows, glassmorphism, floating ambient background blobs, emoji
icon fluff, giant pill controls, heavy drop shadows) with a simple, functional,
trustworthy, university-oriented interface.

Core Color System:
- Page Background: #F7F7F5 (Light neutral canvas)
- Card / Surface: #FFFFFF (White)
- Primary Text: #1F2933 (Slate-900 / Slate-800)
- Secondary Text: #667085 (Slate-600 / Slate-500)
- Borders: #E5E7EB (Slate-200)
- University Maroon Accent: #8B1E2D (bg-university-700, hover:bg-university-800)

Restrained Geometry:
- Cards: ~12px rounded-xl
- Buttons: ~8px rounded-lg
- Badges & Input fields: ~6px rounded-md / rounded-lg
