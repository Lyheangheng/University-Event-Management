==============================================================================
PHASE 16.23B — LINE OFFICIAL ACCOUNT FRIEND LINKING REPORT
==============================================================================

1. OBJECTIVE
------------------------------------------------------------------------------
Integrate LINE Official Account friendship checking (`liff.getFriendship()`) and
friend request prompting (`liff.requestFriendship()`) into the existing LIFF attendance
flow. Ensure students who scan venue QR codes add/unblock the "University Events"
LINE Official Account so they reliably receive outbound attendance push notifications.

2. ROOT CAUSE
------------------------------------------------------------------------------
Previously, a student could successfully authenticate via LINE and link their student ID
to their `lineUserId` record in the database, but might not have added the "University Events"
Official Account as a LINE friend. While the database stored their `lineUserId`, LINE Messaging API
push notification attempts would fail silently or be blocked by LINE if the student was not a friend.

3. FILES CHANGED
------------------------------------------------------------------------------
- `apps/web/src/lib/liff.ts`
  Added `getLiffFriendship()` and `requestLiffFriendship()` helper functions wrapping `@line/liff` SDK calls.
- `apps/web/src/components/attendance/StudentAttendanceForm.tsx`
  Added friendship state, `checkFriendshipStatus` callback, `handleRequestFriendship` action, and friendship banner UI prompt.
- `apps/web/src/app/attendance/session/page.tsx`
  Added friendship status indicator row ("Added" / "Not Added") and "➕ Add Official Account" action button on portal landing page.

4. EXACT IMPLEMENTATION DETAILS
------------------------------------------------------------------------------
1. `liff.getFriendship()` Verification:
   - Invoked after LIFF initialization and LINE token verification / student account resolution.
   - Requires existing `profile` scope (which is already configured in the LIFF application).
   - If `friendFlag` is `true`: Student is already friends with "University Events". No prompt is displayed.
   - If `friendFlag` is `false`: UI displays a clear banner prompting the user to add "University Events" as a LINE friend.
2. `liff.requestFriendship()` Prompt:
   - Triggered when the user clicks "➕ Add Official Account Friend".
   - Opens the LINE subwindow modal prompting the user to add/unblock the linked Official Account.
3. Post-Prompt Re-Verification:
   - Always invokes `liff.getFriendship()` authoritatively after `requestFriendship()` finishes.
   - If `friendFlag` becomes `true`, updates UI state to `isLineFriend = true` and shows success message.
   - If `friendFlag` remains `false`, informs the student that adding the Official Account is required to receive notifications.
4. Error Handling & Fallbacks:
   - If `getFriendship()` or `requestFriendship()` fails/is unsupported (e.g. running outside LINE app in desktop dev mode), logs technical warnings in development mode only and gracefully defaults `isLineFriend` to `true` to ensure attendance submission is not hard-blocked.

5. LIFF FRIENDSHIP FLOW ORDER
------------------------------------------------------------------------------
LINE Authentication (LIFF idToken)
     ↓
Backend Student Verification / Account Linking (`lineUserId`)
     ↓
LIFF Friendship Check (`liff.getFriendship()`)
     ↓
If Friend (friendFlag === true): Continue directly to Attendance Form
     ↓
If Not Friend (friendFlag === false): Display UI Banner & Prompt (`liff.requestFriendship()`)
     ↓
Re-check Friendship (`liff.getFriendship()`)
     ↓
Render Attendance Form with Verified Friendship Status
